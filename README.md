# Reksio UI

The initial goal was to use and improve [ReksioEngine](https://github.com/ReksioEngine/ReksioEngine) in a separate project using AI-first development.

The goal has since shifted to making all five games work by any means necessary using AI-first development, rather than faithfully reimplementing the original engine. This is why compatibility fixes and patches are applied game by game.

- Reksio si Comoara Piratilor
- Reksio si OZN-ul
- Reksio si Magicienii
- Reksio si Masina Timpului
- Reksio si Capitanul Nemo
